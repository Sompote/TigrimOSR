# Marketing Research Report Skill

## Overview
This skill enables conducting thorough marketing research for brands, products, or companies using web searches and compiling findings into structured reports.

## Workflow
1. **Web Search** - Search for information about the brand/product
2. **URL Fetching** - Retrieve specific pages for detailed data
3. **Data Compilation** - Structure findings into tables and sections
4. **Report Generation** - Create comprehensive markdown report

## Output Format

```markdown
# 📊 [Brand/Product] Marketing Research Report

## Executive Summary
[Brief overview of key findings]

## Product Overview
| Aspect | Details |
|--------|---------|
| Product Name | ... |
| Product Type | ... |
| Website | ... |

## Key Findings
- [Finding 1]
- [Finding 2]

## Target Audience
[Description of target demographic]

## Competitive Landscape
[Competitor analysis]

## Marketing Channels
[Recommended channels]

## Recommendations
[Strategic recommendations]
```

## Best Practices
- Handle typos by searching multiple variations (e.g., "AndrewOS" vs "andrewos")
- Always compile data into tables for readability
- Include SWOT analysis when applicable
- Add emoji headers for visual hierarchy
- Fetch official websites for accurate product details
